# CertiK × Gofaizen & Sherle — Partner Intake Landing Page

Co-branded landing page for the CertiK × Gofaizen & Sherle (G&S) partnership.
G&S sends this link to clients; the client fills the intake form; CertiK is
notified by email and the submission is stored in Supabase.

Stack: **Next.js 14 (App Router) · TypeScript · Tailwind CSS 3 · zod · Resend · Supabase** — deployable on Vercel.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in keys (optional for UI work)
npm run dev                  # http://localhost:3000
```

The page renders fully without any env vars; only the form's email/DB
delivery needs them (see below).

## Environment variables

| Variable | Purpose |
| --- | --- |
| `RESEND_API_KEY` | Resend API key for lead notification emails |
| `NOTIFY_EMAIL_TO` | Comma-separated recipients (e.g. `lucas@certik.com,joe@certik.com`) |
| `NOTIFY_EMAIL_FROM` | Verified Resend sender, e.g. `CertiK Partner Intake <intake@yourdomain.com>` |
| `SUPABASE_URL` | Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service-role key (server-only — never `NEXT_PUBLIC_`) |

If **neither** email nor DB is configured, `/api/intake` logs the full
payload to the server console and returns an error to the visitor so no
lead is silently lost. If **one** of the two works, the submission
succeeds and the other channel's failure is logged as a warning.

A commented **webhook alternative** (Zapier/Make/Slack/internal endpoint)
is in `lib/persist.ts`.

### Supabase table

```sql
create table intake_submissions (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  full_name text not null,
  company text not null,
  role text,
  email text not null,
  contact_channel text not null,
  contact_handle text,
  country text not null,
  services text[] not null,
  licensing_status text not null,
  jurisdictions text,
  tech_stack text,
  timeline text,
  additional_info text,
  referral_partner text not null,
  utm jsonb,
  submitted_at timestamptz
);
alter table intake_submissions enable row level security;
-- No public policies: only the service-role key (used by the API route) can write.
```

## Deploy on Vercel

1. Push the repo to GitHub and import it in Vercel (framework auto-detects Next.js).
2. Add the env vars above under **Settings → Environment Variables**.
3. Deploy. The `/api/intake` route runs as a Node serverless function.

Note: the rate limiter (`lib/rate-limit.ts`) is in-memory per serverless
instance — fine for this page's traffic; swap in Upstash Ratelimit for
hard guarantees.

| What | Where |
| --- | --- |

| Trust badges | `config/badges.ts` |
| Investor grid | `config/investors.ts` |
| Testimonials | `config/testimonials.ts` |

| Contact cards + Calendly URL | `config/contacts.ts` |
| Form option lists | `config/form.ts` |
| Design tokens (colors, radius, font, marquee speed) | `styles/tokens.css` + `tailwind.config.ts` |

The hidden `referral_partner` field defaults to "Gofaizen & Sherle" and is
overridable via `?ref=SomePartner`; `utm_*` query params are captured
automatically.

## Replacing logos & photos

Every logo currently in the repo is a **neutral text-wordmark placeholder**
(generated by `scripts/generate-placeholders.mjs`) — the build environment
had no network access to certik.com, so no assets could be downloaded, and
real brand marks should come from official media kits anyway. To replace:
drop an official **monochrome/white SVG** at the same path — no code
changes needed. The marquee renders all logos at a consistent 26px height.

| Path | Replace with |
| --- | --- |
| `public/logos/certik.svg` | Official CertiK white logo |
| `public/logos/gs.svg` | Official Gofaizen & Sherle white logo |
| `public/logos/clients/*.svg` | 36 client logos (filenames match `config/clients.ts`) |
| `public/logos/investors/*.svg` | 12 investor logos (filenames match `config/investors.ts`) |
| `public/photos/lucas.svg`, `public/photos/joe.svg` | Team photos (any raster format works — update paths in `config/contacts.ts` if you change extensions) |
